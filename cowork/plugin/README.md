# Banking Studio for Cowork

Five complementary skills prepare client materials from a director's brief:

- **rabo-banking-materials** — guides the whole assignment and supplies the public-reference Rabobank design assets and digital renderer.
- **ibd-storyline-copywriting** — develops the decision narrative, page headlines and banker-quality copy.
- **public-financial-research** — retrieves public filings/rates and retains source/period/unit provenance; includes explicitly dated public rehearsal data.
- **ibd-financial-modeling** — directs transparent calculations, comparisons, assumptions and sensitivities using the available engine or code execution.
- **rabo-slide-production** — produces editable PowerPoint through the host's available authoring tools and reviews every slide; HTML remains a separate supported output.

Install this package in Claude through Customize → Plugins → Add plugin → Upload plugin. Enable its skills. The plugin has no hooks, background agents, bundled MCP servers or automatic external writes. Public research uses the host's available web/code-execution tools. Paid-provider setup remains optional and requires separate vendor access. Proprietary fonts are not bundled.

Try: “Use Banking Studio to prepare an Apple treasury bond pitch from public sources. Ask about my funding objective and intended client takeaway. Use the Rabobank public-reference design, distinguish benchmark history from current issuer spreads, run inspectable calculations and deliver an editable PowerPoint with source notes.”

Installed skills do not remove subscription limits. Check the actual host's available PowerPoint/code-execution capability before claiming a file was produced. This is an independent external demonstration, not an official bank template or approved banking environment.
