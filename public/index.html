About this demonstration

Layouts use colors and proportions studied in Rabobank’s public H1 2026 results presentation. The original 4:3 slides are adapted to a digital 16:10 canvas. System fonts replace proprietary fonts. This is an external prototype, not an official or approved bank application.

The model stores financial facts, assumptions, method versions, review notes and snapshots in local SQLite. Rust calculates financial outputs. Excel is an inspection export.
