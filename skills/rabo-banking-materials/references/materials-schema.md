# Portable materials contract

The renderer accepts a JSON object with `title`, optional `audience`, `evidence` dictionary and `pages` array (1–20). Each page has `title`, optional `kicker`, optional `message` and `blocks` (1–4). Put the main client conclusion in the title/message, with numerical evidence in bound blocks.

Each evidence entry has `label`, finite numeric `value`, `unit`, `asOf`, `source` (HTTPS URL or `assumption` / `calculation`), optional `classification`, and optional `formula`. For calculated values, also give nonempty `inputs` containing the evidence IDs used in the calculation; cycles are rejected. The renderer checks references and classification, not arithmetic. Model verification remains a separate step. Every numeric entry requires its own source/assumption/calculation classification.

Block types:
- `text`: `text` string, optional `sources` evidence IDs.
- `metrics`: `refs` array of 1–4 evidence IDs.
- `table`: `refs` array of evidence IDs; renders labels, values, dates and classification.
- `bars`: `refs` of 1–12 evidence IDs, all in the same unit; supports positive, zero and negative values. Direct numeric arrays are not accepted.

Example (entirely synthetic):

```json
{
  "title": "Illustrative funding discussion",
  "audience": "CFO and treasury team",
  "evidence": {
    "benchmark": {"label": "Government reference", "value": 4.0, "unit": "%", "asOf": "2026-10-23", "source": "assumption", "classification": "Illustrative"},
    "spread": {"label": "Issuer spread", "value": 1.0, "unit": "%", "asOf": "2026-10-23", "source": "assumption", "classification": "Illustrative"},
    "yield": {"label": "Indicative all-in yield", "value": 5.0, "unit": "%", "asOf": "2026-10-23", "source": "calculation", "classification": "Illustrative", "inputs": ["benchmark", "spread"], "formula": "benchmark + spread"}
  },
  "pages": [{"title": "Prepare execution while testing the cost of waiting", "message": "Current issuer evidence is needed before choosing an execution date.", "blocks": [{"type": "metrics", "refs": ["yield"]}, {"type": "bars", "refs": ["benchmark", "yield"]}, {"type": "text", "text": "Synthetic demonstration. No live issuer spread or execution recommendation is implied."}]}]
}
```

Displayed values are not generated by the renderer. It formats values supplied by verified sources/calculations. Treat issuer spreads, ratings and reported figures with the correct dates and methodological distinctions. Long tables and text must be divided into additional pages after visual review.
