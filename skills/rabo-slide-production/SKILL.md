description: Build and revise editable PowerPoint presentations or digital slide materials for investment banking using the project's Rabobank public-reference visual identity. Use for Rabo-style pitchbooks, financing presentations, investment memoranda and slide-by-slide revisions.
---

Read the companion rabo-banking-materials skill, its assets/brand.json, assets/BRAND_ASSETS.md and retained vector wordmark. Use the user's supplied official template if one becomes available; otherwise describe the output as the public-reference design study, not an official Rabobank template.

Use the host's PowerPoint authoring capability for requested editable .pptx files. Check available authoring tools first; if unavailable, explain that specific limitation and offer the included standalone HTML renderer. Do not claim a PowerPoint file was created when the output is HTML. Do not redistribute proprietary fonts. Prefer authorized installed Myriad-family fonts where available and disclose a fallback when they are absent from the execution environment.

Apply the retained design: 4:3 canvas, white background, navy #000099, orange #ff6700, gray body text, light-weight conclusion headlines, clear hierarchy and restrained charts. Keep the vector logo's proportions. Use only supported bank positioning. Do not add decorative imagery or stock illustrations to financial pages where they obscure the argument.

Before production, create the storyline with the IBD writing skill. Choose a visual that answers the client question: yield history for timing, maturity ladder for refinancing, peer valuation table, value bridge, sensitivity matrix or sources/uses and debt schedule. Use only data types actually present and modeled; do not generate decorative pseudo-data.

Bind every numerical chart/table/card to the saved evidence/model pool. Preserve units, dates, fiscal periods, definitions and assumption labels. For native charts, make chart data editable. Keep source references on the page and detailed lineage in notes or an appendix. Do not reduce font sizes until financial tables become unreadable; split dense pages or move workings into an appendix.

Produce client-ready narrative, meaningful charts, explicit assumptions and source pages together. Render and inspect every slide at presentation size for clipping, collisions, missing fonts, unreadable legends and correct footnotes. Reconcile all displayed values to the model. Keep a review log and the prior version when revising.

Deliver the requested .pptx and, where supported, PDF preview, together with evidence/model inspection files. The test cases are public-data rehearsals and must retain that classification. Do not send the materials externally without the user's instruction.
